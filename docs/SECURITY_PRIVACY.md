# 安全、隐私与儿童数据（P0）

## 1. 身份与权限

- 密码：scrypt + 16 字节随机盐；不存明文；登录限流（IP，20 次/分钟）。
- 令牌：HMAC-SHA256 紧凑令牌，12 小时过期；密钥由 `MATHREALMS_SECRET` 注入；退出仅清空客户端令牌（无状态）。
- RBAC：`student` / `parent` / `admin`；后台路由仅 `admin`。
- 对象级权限：学生会话查询带 `student_id`；家长报告/设置/导出先校验 `family_links` 活跃关系；管理员可查全部。
- 审计：登录、注册、家长绑定/解绑/创建孩子、题目发布、导入预览/入库/回滚、AI 审核、配置变更、数据导出/删除申请写入 `audit_logs`（操作人、角色、对象、IP、请求 ID、时间）。

## 2. 数据最小化

- 学生只需用户名、密码、昵称、年级、教材版本；不收集真实姓名、学校、手机号、位置、通讯录。
- 演示种子数据为虚构账号（小雨/乐乐/小雨妈妈）。
- 家长导出为 JSON，仅包含该孩子的学习记录、掌握度、错题和关卡结果；不含密码哈希。
- AI 任务只传知识点编码/题型/难度/数量，不传学生数据；当前离线 provider 不调用外部服务。
- 前端静态资源不引入第三方分析/广告 SDK。

## 3. 内容与 XSS/SQL

- 所有用户输入使用参数化 SQL；搜索使用 `LIKE` 参数。
- 前端对学生/家长可见文本统一 `escapeHtml`；题目/选项/解析/导入内容均按纯文本处理。
- 导出的 XLSX 单元格按纯文本写入；导入时去除 HTML 标签，不执行公式。
- 响应头：`X-Content-Type-Options: nosniff`、`X-Frame-Options: DENY`、`Referrer-Policy: same-origin`、CSP（`script-src 'self'`，样式允许内联以兼容现有布局）。
- 上传限制：仅 `.xlsx`/`.csv`，8 MB，1000 行；JSON 请求上限 12 MB。

## 4. 未成年人保护

- 学生注册必须勾选监护人同意；首次进入有隐私同意页（已同意学生跳过）。
- 家长中心提供使用设置、数据导出、解除绑定和删除申请。
- 不提供公开社交、评论、好友、排行榜、支付或抽卡。
- 生产上线前需完成：儿童隐私政策、第三方 SDK 清单、数据留存期限、账号注销/删除流程、监护人同意留痕、内容安全审核。

## 5. 已知限制

- 演示令牌无吊销列表；生产建议加入刷新令牌轮换/黑名单或短时令牌 + 服务端会话表。
- 演示未接入 WAF、CSRF Token（当前无 Cookie 会话，风险较低）、验证码、短信验证和真实限流网关。
- SQLite 单文件适合演示；生产建议 PostgreSQL + 连接池 + 只读副本 + 自动备份/PITR。
- AI 内容安全过滤/违法内容处置需在接真实模型时补齐。
