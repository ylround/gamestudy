## 2. 验收标准对照

| 标准 | 实现与验证 |
| --- | --- |
| 角色可登录；越权被拒绝 | 角色路由 + 对象级查询；E2E 学生/家长/管理员；单元测试覆盖会话归属 |
| 取题/作答/判题/提示/解析/战斗/结算/奖励全流程 | 学生 E2E 完整打通；`npm test` 覆盖判题与幂等 |
| 单选、判断、数字、分数判题正确；单位/容差/等价分数 | `judge.ts` 支持容差、等价答案、`a/b`、带单位数值；测试覆盖 |
| 1000 行级导入、错误报告、有效行入库、批次回滚 | 导入预览/提交/回滚；XLSX 模板往返；1000 行上限 |
| AI 任务可创建、失败可重试、仅草稿、未审核不可见 | 任务状态机、草稿表、发布接口；学生端只查 `PUBLISHED` |
| 错题/掌握度/家长报告与答题记录一致 | 同一 `session_questions` 来源；报告聚合 |
| 奖励幂等，弱网重复提交不重复发奖 | 唯一幂等键 + 事务；测试重复结算余额不变 |
| 家长绑定/多孩隔离/导出/删除申请 | 家庭关系校验；报告按 childId；导出/删除审计 |
| 题库发布/导入/AI/权限操作有审计 | `audit_logs`；后台审计页 |
| 兼容适配：平板/PC、横屏、触控 | Playwright 布局审计 1440/1024/768/390/320；无横向溢出；战斗页答题/反馈时战斗场景保持在视口内 |

## 3. 已知缺口 / 非 P0

- `Phaser 3 + React + NestJS + FastAPI + PostgreSQL` 是文档推荐栈；本演示采用零构建 DOM/CSS + Node/SQLite，原因和迁移路径见 `ARCHITECTURE.md`。
- 短信/邮箱/第三方登录、真实对象存储、微信/支付宝、会员订单、教师学校端、推送周报、倒计时自动判负、拖拽/几何题型未实现（P1 或需外部资源）。
- AI 为离线模板 provider，未接真实模型；内容安全过滤、Token 预算和真实成本核算需在接入时补齐。
- 未做真实 HTTPS/域名备案/等保/教育 App 备案/游戏分类；`deploy/` 只提供可运行的容器与反向代理示例。
- 家长使用设置已保存但游戏内尚未强制时段/时长限制（文档列为 P1 家长控制强化）。
- 视觉为暗色奇幻主题；文档默认「明亮卡通 2D」仍属待确认项。
- 难度/题量/奖励曲线为演示数值，需要教研和产品确认后冻结。
- 种子题库由生成器产生，正式试点需按单元审核 300–600 道精审题。
- 未做 40–50 人班级并发压测、弱网自动化、低端平板实测、备份恢复演练。
