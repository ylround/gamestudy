# 角色、服饰与绝招设计

## 1. 参考的市面做法

- **角色收集/编队类 RPG（如 Genshin Impact）**：每个角色有明确的元素、定位、普通攻击和终极技能；玩家按角色差异选择打法，角色等级/突破带来外观与能力成长。[Genshin Impact](https://en.wikipedia.org/wiki/Genshin_Impact)
- **Prodigy Math 的法师/装备体系**：玩家角色可以更换外观和装备，战斗表现与角色/法术绑定；本项目的多角色、多绝招沿用“角色即战斗风格”的思路。[Prodigy: Battling](https://prodigygame.zendesk.com/hc/en-us/articles/12910978061844-Battling-in-Prodigy-Math)
- **难度驱动的动作反馈**：动作游戏通常让高难度敌人/高等级技能拥有更大的镜头震动、粒子和全屏效果；本项目把“题目难度”映射为绝招层级（tier 1/2/3）。

本项目角色、怪物、服饰、图标和动画均为原创 SVG/CSS，不复制任何竞品素材、角色或技能名称。

## 2. 三个可选伙伴

| 伙伴 | 元素 | 战斗特色 | 绝招（1/2/3 级） | 1–2 级服饰 | 3–4 级服饰 | 5+ 级服饰 |
| --- | --- | --- | --- | --- | --- | --- |
| 焰羽 / Pyra | 火焰 | 稳定火焰伤害；终极范围最大 | 火花弹 / 烈焰冲击 / 凤凰天火 | 初行法袍 | 赤焰法袍 | 凤凰法袍 |
| 霜翎 / Frost | 冰霜 | 冰霜护盾：怪物反击伤害 -4 | 冰晶箭 / 霜华连射 / 极寒领域 | 雪原斗篷 | 霜纹斗篷 | 极光斗篷 |
| 雷铠 / Volt | 雷电 | 连击大师：每层连击额外 +2 伤害 | 雷光掌 / 连锁闪电 / 九霄雷劫 | 雷鸣短打 | 雷纹战衣 | 九霄战甲 |

每个角色有独立的经验、等级、当前服饰和解锁状态。切换角色会同时切换战斗数值特色、角色外观、绝招名称和特效颜色；等级和进度不会丢失。

## 3. 等级、服饰与绝招

- 角色经验来自答题结算；与账号总经验分开累计，角色等级用同一经验曲线计算。
- 服饰分三档：
  - Lv.1–2：基础服饰；
  - Lv.3–4：进阶服饰（肩甲/斗篷/腰带等叠加在角色 SVG 上）；
  - Lv.5+：终极服饰（光环、王冠/披风、元素粒子）。
- 角色 SVG 使用同一 `viewBox` 的“基础角色 + 服饰层”组合，所以升级后仍是同一个人物轮廓，但服饰、光环和颜色明显不同。
- 绝招名称按题目难度（关卡 1/2/3）选择对应层级；Lv.3 / Lv.5 解锁中级/终极绝招标记。高难度关卡直接播放更夸张的终极动画。
- 结算页显示角色等级、当前服饰、新解锁服饰/绝招；成长页显示角色图鉴、当前服饰和三档绝招。

## 4. 难度 → 特效强度

| 题目/关卡难度 | 绝招层级 | 表现 |
| --- | --- | --- |
| 1（基础） | Tier 1 | 普通法术球、命中闪光、伤害数字、血条过渡 |
| 2（进阶） | Tier 2 | 更大法术球、更强闪光/抖动、更大伤害数字 |
| 3（挑战） | Tier 3（终极） | 角色专属颜色、全屏闪光、双层光环、6 个粒子、竞技场震动、超大绝招名与伤害数字 |

角色颜色覆盖法术球、绝招名、光环、粒子和血条损伤高光；同一难度下三个角色的视觉表现明显不同。

## 5. 数据与接口

- `character_saves(user_id, character_id, xp, selected)` 保存每个角色的经验与当前选择；`selected=1` 表示当前出战角色。
- `GET /api/v1/game/characters` 返回三名角色（等级、经验、服饰、绝招解锁、选中状态）。
- `POST /api/v1/game/characters/:id/select` 切换出战角色。
- `GET /api/v1/game/save` / 登录响应包含 `character` 与 `characters`。
- 答题反馈返回 `cast: { tier, name, ultimate, color, effect }` 与 `character`；结算返回 `character`（等级、服饰、解锁）。
- 战斗会话在创建时固定 `characterId`，避免中途切换角色影响已开始的战斗。
